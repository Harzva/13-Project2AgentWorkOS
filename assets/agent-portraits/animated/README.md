# Animated Agent Portraits

This folder stores the animated SVG set used by the README Agent Swarm table.

GitHub README rendering supports normal image embedding, and GIF is the safest motion format. Animated SVG can work when the animation is self-contained CSS inside the SVG and referenced as an image, but it should be treated as progressive enhancement rather than the only visual proof.

The static portraits in `assets/agent-portraits/` remain the fallback set.
