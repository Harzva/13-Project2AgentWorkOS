# Agent Portrait Assets

This folder stores the first public-safe visual identity set for the AgentWorkOS role library.

## Mapping

| Role | Avatar | Source meaning |
|---|---|---|
| `project-inventory` | `project-inventory.svg` | workspace discovery and status inventory |
| `project-alchemist` | `project-alchemist.svg` | scientist / project reflection to AgentWorkOS assets |
| `role-planner` | `role-planner.svg` | role responsibility planning |
| `memory-rule-manager` | `memory-rule-manager.svg` | durable knowledge and rules |
| `codex-setup` | `codex-setup.svg` | local Codex and tool integration |
| `release-manager` | `release-manager.svg` | public release and proof |
| `quality-reviewer` | `quality-reviewer.svg` | evidence and risk review |

## Source Rule

These SVG files were promoted from local generated asset pools into this repository as AgentWorkOS role assets.

The repository keeps only selected public-safe SVGs, not the entire source folders.

Future versions can add alternate portrait styles from the portrait asset pool, but each role should keep one default avatar to avoid visual ambiguity.
