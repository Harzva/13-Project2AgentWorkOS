# RELEASE_CHECKLIST

## Before Publishing

- [ ] Repository name explains the project without private context.
- [ ] GitHub description states the input, transfer process, and output.
- [ ] README first screen explains what the project is.
- [ ] README includes a real screenshot, diagram, or proof image.
- [ ] Similar projects were checked and merged or linked.
- [ ] Main project status is clear: Active / Watch / Archive / Reference.

## AgentWorkOS Transfer

- [ ] Agent roles extracted.
- [ ] Memory rules extracted.
- [ ] Repeatable skills identified.
- [ ] MCP/tool needs listed.
- [ ] Workflow documented.
- [ ] Non-repeatable mistakes turned into rules.
- [ ] Repeated lifecycle checks turned into hook candidates.

## Public Proof

- [ ] Local files render correctly.
- [ ] Links use relative repo paths or public URLs.
- [ ] No private absolute paths are required for readers.
- [ ] Release, GitHub Pages, or article path is decided.
- [ ] Post-release review is scheduled.
