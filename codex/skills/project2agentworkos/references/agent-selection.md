# Agent Selection Reference

Pick roles by the work's failure risk.

| Failure risk | Role to use |
|---|---|
| Unknown project state | Project Inventory Manager |
| Too many ideas, no closure | Project Alchemist |
| Role system is unclear | Role Planner |
| Useful thread may be forgotten | Memory Rule Manager |
| Local `.codex` install or skill work | Codex Setup Manager |
| Public GitHub release | Release Manager |
| Big claims without proof | Quality Reviewer |

When in doubt, use:

```text
Primary: Project Alchemist
Verifier: Quality Reviewer
```
