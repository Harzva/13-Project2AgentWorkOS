# Codex Substrate Reference

`.codex` is the local substrate, not the whole AgentWorkOS.

Useful public-safe targets:

- `<codex-home>/skills/<skill-name>/SKILL.md`
- `<codex-home>/memories/*.md`
- `<codex-home>/rules/*.rules`

Never publish or copy into the repo:

- auth files
- account files
- sqlite databases
- raw sessions
- private local config
- token material

Use distilled content only.
